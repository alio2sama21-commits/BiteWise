إعدادات Sign in with Google و Gmail OTP

اربط حسابك المجاني مرة واحدة عشان الدخول بجوجل يفتح شاشة Google الحقيقية وكود الـ OTP يوصل لـ Gmail فعلياً.

1. الدخول الحقيقي عبر Google OAuth 2.0

احصل على Client ID مجاناً من Google Cloud Console → Credentials → Web Application، وأضف http://localhost:8765 في Authorized JavaScript origins.

2. إرسال كود OTP تلقائياً لأي Gmail يكتبه المستخدم (عبر Gmail SMTP)

ملاحظة مهمة: هنا بتكتب إيميلك أنت كصاحب الموقع مرة واحدة بس (الحساب اللي هيخرج منه الكود). بعد كده، أي مستخدم يكتب أي Gmail في صفحة التسجيل هيوصله الـ OTP تلقائياً على إيميله! احصل على App Password (16 حرف) من myaccount.google.com/apppasswords.

3. تشغيل إرسال الـ OTP على GitHub Pages (لما ترفع الموقع أونلاين 24/7)

لأن GitHub Pages استضافة ثابتة، اربط حساب EmailJS مجاني بإيميل Gmail بتاعك وحط المفاتيح هنا (أو في ملف config.js) عشان الـ OTP يوصل لأي مستخدم أونلاين.
